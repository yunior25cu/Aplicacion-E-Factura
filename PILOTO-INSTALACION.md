# Guía de Instalación - Balaxys Efactura (Piloto)

Esta guía detalla los pasos para instalar la aplicación **Balaxys Efactura** en dispositivos Android fuera de la Google Play Store.

## 1. Requisitos previos
- Dispositivo con **Android 7.0 (API 24)** o superior.
- Espacio libre mínimo: 50 MB.
- Conexión a Internet para el primer inicio de sesión.

## 2. Instrucciones de Instalación
1. Descargue el archivo de la variante deseada:
   - Producción: `BalaxysEfactura-prodRelease-v1.0.apk`
   - Desarrollo/Pruebas: `BalaxysEfactura-devRelease-v1.0.apk`
2. Al abrir el archivo, es posible que Android muestre una advertencia: *"Por seguridad, el teléfono no tiene permiso para instalar aplicaciones desconocidas de esta fuente"*.
3. Pulse en **Ajustes** y active la opción **"Permitir desde esta fuente"**.
4. Regrese e inicie la instalación pulsando **Instalar**.

## 3. Actualización de Versión
Para actualizar una versión anterior:
- Simplemente descargue el nuevo APK y ábralo.
- Android le preguntará si desea instalar una actualización. Sus datos de sesión se mantendrán.
- **Importante:** Las versiones **DEV** y **PROD** pueden coexistir en el mismo dispositivo como aplicaciones separadas.
- Si recibe un error de "Aplicación no instalada" o "Conflicto de firma", deberá desinstalar la versión anterior antes de instalar la nueva.

## 4. Primeros Pasos
1. Inicie la aplicación desde el icono correspondiente:
   - **Balaxys Efactura**: Versión estable.
   - **Balaxys DEV**: Versión de pruebas.
2. Introduzca sus credenciales proporcionadas.
3. Verifique que puede visualizar su listado de CFEs y que el nombre de su empresa aparece correctamente.

## 5. Soporte y Reportes
En caso de errores o bloqueos:
- Realice una captura de pantalla del error.
- Envíe el reporte al equipo técnico indicando su modelo de celular y versión de Android.
